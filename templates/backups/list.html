Restoring a backup

Restoring replaces all current data, so it is done on the server, not from this page:

  1. Stop the HotelIT Server, HotelIT Jobs and HotelIT Backup scheduled tasks.
  2. In PowerShell, in the application folder: .\.venv\Scripts\python.exe manage.py restore_backup <file name>
  3. The backup is verified first and a safety backup of the current state is made automatically. Type RESTORE to confirm.
  4. Start the scheduled tasks again and check a few recent records.

Full procedure, including restoring onto a new server: docs/BACKUP_AND_RESTORE.md.
